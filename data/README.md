# Данные организаторов

Положите сюда комплект «Нефтекод 2.0» как есть: `data.rar` (или распакованные
`242000_tags.csv`, `avt_tags.csv`) и XLSX ЛИМС, ПАК и `Теги_хакатон.xlsx`.
Docker и `scripts/start.py` импортируют их один раз при первом запуске.

Данные в репозиторий не коммитятся: они конфиденциальны и весят ~350 МБ.
