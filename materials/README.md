# Исходные материалы организаторов

В этой папке сохранены все содержательные файлы исходного комплекта. Служебные `.DS_Store` и временные lock-файлы Office `~$…` не включены, поскольку не содержат материалы кейса.

## Данные

`data.rar` содержит два исходных CSV. В отдельной распакованной папке организаторов лежат файлы с теми же именами и размерами; их контрольные суммы приведены ниже. Доступная в среде старая версия p7zip прочитала каталог, но не поддержала метод распаковки RAR5, поэтому побайтовое сравнение архива с отдельными копиями в этой проверке не выполнено.

| Путь в архиве | Размер | SHA-256 отдельной копии из пакета |
| --- | ---: | --- |
| `data/242000_tags.csv` | 91 324 015 байт | `19b9744e6315a395d3d77ac53a6e09b6d69488fa7f84bd21147cd8d7c9be7e21` |
| `data/avt_tags.csv` | 247 429 640 байт | `514adfcad05c1e7bd80616889bfe8bb0617aad792ab4248f178a721606f0e10f` |

Извлечённые CSV не продублированы в Git: `avt_tags.csv` превышает лимит одного файла GitHub, а архив уже является исходным файлом организаторов и содержит оба CSV. Для анализа структуры без распаковки см. `../data_sources.md` и [справочник тегов](../tag_dictionary.md).

Распаковка в среде с актуальным 7-Zip/UnRAR:

```bash
7z x data.rar
```

Старая сборка p7zip 17.05 умеет показать состав RAR5, но может вернуть `Unsupported Method`; это ограничение распаковщика, не признак повреждения архива.

## Приоритет версий

- `Updates/теги АВТ_24-2000.xlsx` заменяет смысл/единицы листа КИП исходного `Теги_хакатон.xlsx`.
- `Updates/формулы_ВАК.xlsx` заменяет лист ВАК исходного `Теги_хакатон.xlsx`.
- `Updates/Ustanovka_AVT_merged.pdf` — не только АВТ: страницы 2–4 описывают гидроочистку, блендинг и всю цепочку.
- Три `doc00628….pdf` — детальные страницы АВТ с рукописно нанесёнными короткими тегами.
