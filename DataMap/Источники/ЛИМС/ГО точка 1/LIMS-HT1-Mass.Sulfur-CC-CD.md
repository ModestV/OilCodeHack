# HT1: Mass.Sulfur

**Исходная точка:** Установка 'Гидроочистка'. Точка отбора '1'. Продукт 'ФРАКЦ_ДИЗ'.

**Показатель:** `Mass.Sulfur`. [Что означает показатель](../../../%D0%9F%D0%BE%D0%BD%D1%8F%D1%82%D0%B8%D1%8F/%D0%A1%D0%B5%D1%80%D0%B0.md).

| Поле | Содержание |
| --- | --- |
| Файл и лист | ЛИМСы 01.01.2023 - н.в_ (2).xlsx; Лист1 |
| Пара столбцов | CC: дата, CD: значение; измерения с строки 5 |
| Заголовки | CC1/CD1: точка (может быть пустой частью общего заголовка); CC2: показатель; CC3: единица; CC4: заявленный счётчик |
| Единица источника | % масс. |
| Объект строки | Один результат одного показателя одной точки; не вся проба целиком |
| Записей с датой / числовых | 132 / 132 |
| Числовых внутри периода CSV | 132 |

Явная конвертация в мг/кг: `value_mg_kg = value_source * 10000`. Входную серу нельзя сравнивать с выходной до конвертации; пробам разных точек также нужен транспортный лаг.
