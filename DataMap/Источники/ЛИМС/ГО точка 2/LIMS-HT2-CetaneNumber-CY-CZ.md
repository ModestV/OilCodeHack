# HT2: CetaneNumber

**Исходная точка:** Установка 'Гидроочистка'.. Точка отбора '2'. Продукт 'Дизельное топливо'

**Показатель:** `CetaneNumber`. [Что означает показатель](../../../%D0%9F%D0%BE%D0%BD%D1%8F%D1%82%D0%B8%D1%8F/%D0%A6%D0%B5%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BE%D0%B5%20%D1%87%D0%B8%D1%81%D0%BB%D0%BE.md).

| Поле | Содержание |
| --- | --- |
| Файл и лист | ЛИМСы 01.01.2023 - н.в_ (2).xlsx; Лист1 |
| Пара столбцов | CY: дата, CZ: значение; измерения с строки 5 |
| Заголовки | CY1/CZ1: точка (может быть пустой частью общего заголовка); CY2: показатель; CY3: единица; CY4: заявленный счётчик |
| Единица источника | ед.цет.ч. |
| Объект строки | Один результат одного показателя одной точки; не вся проба целиком |
| Записей с датой / числовых | 42 / 42 |
| Числовых внутри периода CSV | 42 |

## Правила чтения и ограничения

- Временная метка источника не подтверждена как время доступности анализа; см. Q03.
- Меньше 150 числовых проб: высок риск нестабильной оценки модели и редкого покрытия режимов. Не увеличивать размер выборки переносом одной метки на 10-минутную сетку.
