# ЛИМС: лабораторные анализы

Файл `ЛИМСы 01.01.2023 - н.в_ (2).xlsx`, лист `Лист1`. 108 колонок: 54 независимые пары дата/значение в 6 точках. Всего 36806 записей с датой, из них 36800 числовых и 6 `Pt Created`. В строке счётчиков заявлено 36808.

## Скелет Excel

| Строка/колонки | Назначение |
| --- | --- |
| 1 | Название точки, общие/разреженные заголовки; распространять только в зоне заголовка |
| 2 | Имя показателя для пары |
| 3 | Исходная единица; некоторые единицы спорные |
| 4 | Заявленное количество; проверять фактические записи |
| 5 и далее | Измерения: дата слева, raw-значение справа |
| A:B, C:D, ... DC:DD | 54 отдельных ряда; дата соседней пары может быть другой |

## Чтение в длинный формат

1. Обходить пары столбцов, восстановить точку только по строке заголовка.
2. Для каждой пары сохранить parameter, unit_source, source_columns и source_row.
3. Разобрать собственную дату и число; Pt Created сохранить как raw с флагом, числовое значение null.
4. Объединить пары вертикально: одна строка на результат, идентификатор включает точку и пару.
5. Не заполнять целевые метки вперёд ради увеличения числа проб; отдельно считать возраст последнего доступного анализа.

Рекомендуемые поля: `series_id, point_raw, parameter_raw, unit_source, event_time, available_at, value_raw, value, quality_flags, source_columns, source_row`. available_at пока неизвестен; не заполнять его временем пробы без маркировки допущения.
