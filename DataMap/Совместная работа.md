# Совместная работа с vault

Открывать как хранилище именно папку `DataMap` внутри Git-репозитория. Ветка первой итерации: `Human-DataMap`.

## Первый запуск

Из корня репозитория при закрытом vault:

```powershell
python tools/setup_vault.py
```

Скрипт без внешних Python-зависимостей устанавливает включённый Folder Notes 1.8.26 из локальной копии релиза. Он добавляет folder-notes к списку существующих плагинов, не заменяя список целиком. В Obsidian может потребоваться разрешить сторонние плагины (Restricted mode); это отдельное доверие самого приложения. После запуска открыть vault заново.

## Что общее, что личное

В Git хранятся Markdown, изображения, шаблоны, установщик и зафиксированный релиз плагина с лицензией и SHA-256. Вся `DataMap/.obsidian/` и `.trash/` игнорируются. Тема, раскладка, вкладки, hotkeys, остальные плагины, их настройки и локальные обновления не попадают в коммиты. Git не умеет «один раз положить tracked-файл и больше его не обновлять», поэтому начальная установка сделана отдельным шагом.

При повторном запуске существующая версия Folder Notes и data.json сохраняются, а включение добавляется при отсутствии. Если плагин позже намеренно выключен, повторный запуск снова включит его. Неполная установка или повреждённый список плагинов приводят к сообщению об ошибке без попытки исправлять настройки наугад. templates.json создаётся только если его нет. Существующие app.json, appearance.json, core-plugins.json, hotkeys.json и workspace-файлы не меняются.

Настройка Folder Notes для нового пользователя: заметка `Имя папки.md` внутри одноимённой папки; автоматическое создание и совместное удаление отключены. При существующих иных настройках пользователь выбирает эту схему сам. Других обязательных community-плагинов нет. Достаточны стандартные Search, Backlinks, Outgoing links, Graph, Properties и Templates; Dataview/Templater не нужны для чтения карты.

## Как редактировать

Карточки - обычные Markdown-файлы; команда редактирует их напрямую. При новом подтверждении сохранить raw, добавить источник ответа и обновить связанные вопросы. Идентификаторы AVT-/HT-/LIMS- не сокращать до неоднозначного T6. Для новых карточек есть шаблоны; незаполненные шаблоны не являются фактическими данными.

Генератор первой итерации не является системой синхронизации ручных правок. Безопасный повторный запуск создаёт карту в новом каталоге для сравнения. В рабочий DataMap он откажется писать поверх существующих заметок. После генерации переносить нужные изменения через обычный review Git.

Обновление карты: git pull, затем review и commit только своих изменений. Личные .obsidian-файлы не добавлять через git add -f. Проверка структуры и ссылок: `python tools/datamap/validate_map.py`. Перед коммитом больших обновлений сравнить список охваченных тегов/рядов и обновить дату проверки.
