# Кинематическая вязкость

ViscosityK: отношение динамической вязкости к плотности. Число имеет смысл вместе с температурой испытания.

**Ожидаемая размерность по смыслу:** обычно мм2/с; единица и температура в формуле не подтверждены. Это пояснение термина, не исправление заголовка источника.

В пакете присутствует формула для фракции 350-500; соответствующего лабораторного ряда среди 54 рядов не найдено. Не объявлять формулу проверенной по другим показателям.
