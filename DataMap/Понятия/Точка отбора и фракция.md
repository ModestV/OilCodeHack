# Точка отбора и фракция

Точка отбора задаёт место лабораторного контроля. Фракция задаёт часть продукта, например диапазон кипения 240-350. В пакете нет однозначной таблицы точка АВТ -> фракция ВАК -> линия на схеме. Общие слова Дизельное топливо недостаточны для объединения проб.
