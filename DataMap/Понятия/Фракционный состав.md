# Фракционный состав

T50, T90 и T95: температуры, соответствующие отгону 50, 90 и 95% по применённой методике. IBP.T / IBP: начало кипения; EBP.T / EBP: конец кипения. I250 и I350: обычно объёмная доля, отогнанная до 250 и 350 °C; точную методику нужно подтвердить.

**Ожидаемая размерность по смыслу:** температуры: °C; I250/I350: обычно % об.. Это пояснение термина, не исправление заголовка источника.

I350 не является температурой T350. Значения одной кривой могут проверяться на порядок только для одной пробы и совместимой методики; даты разных пар Excel различаются.
