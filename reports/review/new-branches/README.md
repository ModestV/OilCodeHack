## Почему v4 пока не заменяет runtime

1. `DynamicsData.rows(..., between=...)` ограничивает время начала,
   но не конец будущего окна цели (горизонт + 30 минут). На реальных
   данных обнаружены строки, пересекающие границу временного фолда;
   для фолда 2025 и H3 — по 7 строк каждого анализатора.
2. quiet_future проверяет лишь начальное и конечное управление.
   Воспроизводимый пример T6 350→360→350 за час ошибочно признан стабильным.
3. Stage2 выбирает alpha и оценивает остатки на том же валидационном
   фолде; OOF-проверка применимости использует всю fit-историю вместо
   истории конкретного фолда. Такие интервалы не независимо калиброваны.
4. Свежесть CN увеличена до 60 суток, T95 — до 7 суток без подтверждения.
   Это ослабление требований к доказательствам, а не прирост точности.
5. Полное слияние теряет нашу модель партии, запасов и транспортной задержки.
6. Пропущенные критерии Парето превращались в нулевую стоимость/нагрузку.
   В адаптированном коде исправлено и проверено отдельными тестами.

Кандидат перспективен для коротких горизонтов. Условие повторного рассмотрения:
исправить границы всех target/response окон, проверять весь управляющий путь,
получить честные OOF-остатки и поддержку внутри фолдов, повторить одинаковое
покрытие/метрики, затем интегрировать через адаптер с сохранением процесса.
