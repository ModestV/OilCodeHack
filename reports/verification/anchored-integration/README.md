# Интеграция прогноза с партией и блендингом — 21.09.2026

Ветка `codex/integrated-anchored-forecast` объединяет процессную модель из
`903ae91` и исправленный прогноз из `852af10` (развитие Claude `ddb8e4c`).
Перенесены forecast, признаки, артефакты и исследования; сценарии и агенты
адаптированы выборочно, чтобы сохранить массовый баланс, запасы, доставку,
рецепт, присадку и экономические варианты.

## Работающий расчёт

- API `/forecast` принимает горизонт 0–180 минут; `/decision` использует
  тот же горизонт и одну общую оценку для всех кандидатов.
- Исходная сера — допустимый H0, дальнейшая база — прогноз H0/H1/H2/H3.
  Между опорными точками сценарий линейно интерполирует концентрацию;
  точный прогноз запрошенной конечной точки сохраняется. Это допущение
  интегрирования партии, отдельное от log-интерполяции forecast API.
- Условные управляющие эффекты добавляются с прежними лагом и задержкой.
  Качество нового поступления — интеграл концентрации по интервалу
  `[0, горизонт − доставка]`, делённый на его длительность. Производительность
  постоянна внутри сценария и учитывает изменение подачи. Масса и сера
  затем смешиваются с существующим запасом; шаг отображения не меняет баланс.
- Недопустимость любой нужной опорной точки блокирует рекомендацию по
  наблюдаемым данным. Ручная базовая сера оставляет условный плоский сценарий.
- Для связанной партии проверка риска использует максимум верхних границ
  прогноза на **прибывающем участке**, затем тот же баланс массы и запаса,
  без зачёта благоприятного управляющего эффекта. Это эвристический запас,
  не 80%-й интервал качества партии и не доказанная вероятность безопасности.
- Прямой выпуск сохраняет независимую тревогу прогноза и товарный предел S10.
  Экспериментальный классификатор риска не включён.
- `backend/forecast_legacy.py` сохранён для ранних replay и неизменного
  распределения условного индекса нагрузки. Активный прогноз — `backend/forecast.py`.
  Новые признаки — `anchored_features.py`; старые исследования используют
  прежний `sulfur_features.py`. Нагрузка не является вероятностью отказа.

## Проверки

- 123 pytest: backend, модельные и исследовательские проверки; 9 unittest
  ранних моделей (частично пересекаются); 11 frontend-тестов, TypeScript/build.
- Инварианты: интеграл переменного прогноза, доставка, запас, промежуточный
  пик риска, отсечение отрицательной серы, мгновенный отклик, независимость
  от шага графика, H1 вместо H3, однократный прогноз, отказ при неполной траектории.
- [Реальный API](api-integration.json): H0/H1/H2/H3, отказ HTTP 422 при H181,
  исторический H1 со связанной партией, точное воспроизведение выбранного
  `model_request` через `/scenario`, отказ при нулевом поступлении и нехватке запаса.
  При заданных пользователем свойствах резервуаров: 30 т поступления за
  45 минут, сера поступления 6.813685, смесь 4.734834 мг/кг. Запасы и свойства
  резервуаров здесь синтетические входы сценария, не измеренная история завода.
- [Offline/runtime parity](../../modeling/causal-anchored/runtime-parity.json):
  воспроизведение доступной истории для 1012 строк каждого из двух артефактов;
  признаки, допустимость, концентрация, интервал и вероятность, плюс прямые
  чтения Parquet в контрольных точках. Файл содержит SHA текущего скрипта и моделей.
- UI: локальный production build `http://127.0.0.1:8011/`, встроенный браузер,
  viewport 1265×712. Путь: «Рекомендации» → «Рассчитать сценарий» → отказ
  из-за цетана и блок прогноза. Видны 8.63 мг/кг, интервал 6.33–10.37,
  вероятность 15.8%, признаки 15/15, корректная подпись модельной оценки.
  Страница не пустая, нет error overlay, консоль error/warn пуста; скриншот
  проверен. Мобильный viewport и исторический ввод даты в UI здесь не подтверждены;
  исторический сценарий проверен через API. Использован CUA; отдельный Browser
  plugin не доступен в каталоге, внешняя автоматизация браузера не использовалась.


## Оставшиеся ограничения

Причинность управляющих эффектов и промышленные ограничения не установлены;
интервалы имеют дрейф (фактическое покрытие 2026 около 75–77% при номинале 80%).
Модель пропускает часть превышений. Качество смеси не получает автоматически
вероятность точечного прогноза ГО. Реальные остатки резервуаров, свойства
компонентов и экономические коэффициенты отсутствуют. LLM-слой ещё не реализован.

Следующий предметный шаг: отдельная постановка и проверка риска превышения
с ценой пропуска/ложной тревоги на временных фолдах; затем новый независимый
период. Редкий цетан требует отдельной модели/источника данных и проверки её
применимости; увеличение срока свежести не заменяет это доказательство.
