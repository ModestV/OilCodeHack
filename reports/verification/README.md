# Проверка контура прогноза и рекомендаций

Актуальная реализация: ветка `fix/forecast-accuracy` (на базе `main` d8afb0b). Точные SHA/даты каждого измерения находятся в JSON; отчёт не переносится автоматически на изменённый код.

## Артефакты доказательств

- `../modeling/sulfur-forecast/REPORT.md`, `metrics.json`, `model.json`, `predictions.csv`: модель v3 (калиброванный по ЛИМС nowcast/forecast), временные фолды, метрики по горизонтам, отклики на управляющие воздействия.
- `agent-backtest/REPORT.md`, `results.json`, `decisions.csv`, `vak.csv`: прогон реального контура решений по всем 253 пробам серы 2026 года в момент `проба − 3 ч` и сравнение всех 17 ВАК с лабораторными рядами.
- `feature-parity.json`: 48 origin × горизонт; runtime-прогноз совпадает с offline benchmark с точностью 1e-6.
- `local.json`: 8 API-сценариев (`cases.json`) на локальном наборе `hackathon`.
- `server.json`, `deploy.json`: результаты предыдущей версии на сервере; после слияния требуется повторный запуск `verify_release.py --base-url ...`.
- `../modeling/sulfur-first-iteration/`: отчёт предыдущей (заменённой) модели — сохранён как история; артефакт не загружается runtime.

Локальные проверки: **82 pytest**, **3 modeling unittest**, **11 frontend tests**, TypeScript и production build.

## Что показал бэктест контура (2026, 253 пробы)

| оценка | n | MAE, мг/кг | corr |
|---|---:|---:|---:|
| nowcast в момент отбора пробы | 238 | 1.18 | 0.36 |
| прогноз контура на 180 мин | 236 | 1.46 | 0.17 |
| константа (медиана обучения) | 236 | 1.48 | — |
| предыдущая опубликованная проба | 233 | 1.71 | 0.16 |

- Прогноз выдан для 93.3 % проб; 13 отказов — режим вне области обучения (остановы), 9 — нет телеметрии/признаков. Среди отказов 2 реальных превышения.
- Вероятность превышения на 180 мин: AUC 0.59, Brier = климатологии; тревога при P ≥ 0.2 находит 41 % превышений при 23 % ложных тревог. На горизонте 0 AUC 0.84. Это честный предел: суточная проба за 3 часа предсказуема слабо.
- Решений: 186 рекомендаций (156 hold, 30 корректирующих с ростом T6), 67 отказов (50 — ни один кандидат не прошёл проверки T95/цетана/риска, 12 — нет допустимого прогноза, 5 — устаревшие данные).
- Эффект рекомендованных изменений исторически не проверяем (контрфактических данных нет).

## ВАК против ЛИМС (весь период)

- `24-2000:GODT:D15` ↔ `lims.ht.2.D15`: MAE 1.67 кг/м³, corr 0.64 (константа 2.09) — рабочий виртуальный анализатор.
- `24-2000:GODT:IBP`: MAE 5.7 °C, corr 0.54, смещение +4 °C — полезен после калибровки.
- `24-2000:GODT:T95`: MAE 6.1 °C, corr 0.43, ≈ константа — используется как резерв при устаревшем ЛИМС.
- `24-2000` T50/T90/I250/CFPP/CloudPoint: корреляция ≤0.3, смещения до 12 единиц — только диагностика.
- АВТ: `AVT6:240-350:T50` лучше всего совпадает с точкой 3 (MAE 3.8 °C, corr 0.31), `AVT6:350:T50` — с точкой 1 (MAE 4.8 °C, corr 0.51): гипотеза «точка 3 = 240–350, точка 1 = фракция до 350». `AVT6:240-350:EBP` даёт ~465 °C (MAE >60 °C) и помечена `invalid`.

## Демонстрация за несколько минут

1. Открыть `/`, показать мониторинг, разные источники и диагностику.
2. Рекомендации → Момент в истории → `2026-01-08 07:00`: nowcast 8.6 мг/кг, удержание режима, 3 кандидата, интервал и P(>10).
3. `2026-01-14 07:00`: проба ЛИМС 11.1, nowcast 10.8, прогноз без воздействия 9.9 (P(>10) 44 %) — hold недопустим, предложено +2.6 °C T6 → 9.0 мг/кг (P 24 %).
4. `2026-06-19 12:00`: останов установки — режим вне области, отказ. `2026-08-08 12:00`: устаревшие управляющие измерения, отказ.
5. Песочница: рост серы в сырье с 0.93 до 1.15 % масс. — модель предлагает поднять температуру; сумма долей 90 % возвращает объяснимую ошибку.

## Открытые ограничения

Не подтверждены причинные эффекты управления (коэффициенты — наблюдательные отклики анализатора), совместная управляемость T6/F9/P13, промышленные диапазоны, полная сезонная спецификация, точки лабораторных входов ВАК и соответствие точек ЛИМС АВТ фракциям. Nowcast и прогноз относятся к выходу гидроочистки, не к товарной смеси.
