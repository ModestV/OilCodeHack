# Проверка первой итерации

Актуальная реализация: `main`; backend и модель, проверенные на сервере, — commit `63e69cb`. Последующие изменения интерфейса проверяются отдельно. Точные SHA/даты каждого измерения находятся в JSON, поэтому отчёт не следует автоматически переносить на изменённый код.

## Артефакты доказательств

- `server.json`: 8 успешных API-сценариев на реальном серверном наборе `hackathon`, запросы и trace, ограничения/прокси каждого кандидата, отдельный прогноз; проверен SHA `63e69cb`.
- `local.json`: тот же сценарный набор локально до финальных косметических изменений; не доказательство текущей версии сервера.
- `cases.json`: воспроизводимые даты, входы и ожидаемые результаты.
- `feature-parity.json`: 6 реальных origin; значения признаков из исходных CSV/XLSX сопоставлены с Parquet/runtime, затем прогнозы API с offline benchmark. Есть момент 11:58:15 между отсчётами.
- `deploy.json`: GitHub Actions run [35484733521](https://github.com/ModestV/OilCodeHack/actions/runs/35484733521), все шаги успешны, включая SSH, rsync, restart и публичную проверку SHA.
- `../modeling/sulfur-first-iteration/REPORT.md`, `metrics.json`, `predictions.csv`, `model.json`: временная валидация, область применимости, артефакт инференса и поштучные результаты.

Локальные проверки: **65 pytest**, **5 modeling unittest**, **11 frontend tests**, TypeScript и production build. CI повторяет эти команды на Python 3.12 / Node 22.12. Проверки не подменяют оценку точности и не подтверждают промышленную безопасность.

## Демонстрация за несколько минут

1. Открыть `/`, показать мониторинг, разные источники и диагностику.
2. Рекомендации → Момент в истории → `2026-01-08 07:00` → Рассчитать: удержание режима, 3 кандидата, прогноз на 10:00, показатели и trace.
3. `2026-01-14 07:00`: опубликованная сера 11.1 мг/кг, отказ, объяснение и альтернативы остаются видимыми.
4. `2026-08-08 12:00`: устаревшие управляющие измерения, численный прогноз и рекомендация не выдаются.
5. Песочница: изменить сырьё/режим/горизонт, показать конец траектории и смесь; сумма долей 90% возвращает объяснимую ошибку.

## Численный результат и открытые ограничения

На 214 принятых test-пробах из 253 (84.6%) MAE Ridge=1.409 против 1.609 у доступной предыдущей пробы, примерно 12.4% улучшения на одинаковых строках. Отклонено 39 проб, среди них 4 превышения. На всех строках сырой Ridge MAE=2.015 (baseline на 249 доступных строках=1.808 — разные знаменатели). После gate recall Ridge=1/32, guard=7/32. Это измеренное преимущество по средней ошибке внутри области применимости, с серьёзным ограничением по обнаружению превышений.

Не подтверждены причинные эффекты управления, совместная управляемость T6/F9/P13, промышленные диапазоны, полная сезонная спецификация, точки некоторых лабораторных входов ВАК и конфликт CFPP. Они не скрыты за зелёными unit-тестами. Первая итерация доказывает воспроизводимость анализа и работоспособность условного decision-контура; эффект на реальный выпуск/затраты/ресурс требует дальнейшей валидации.
