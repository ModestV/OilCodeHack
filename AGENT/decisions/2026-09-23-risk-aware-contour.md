# 2026-09-23 — контур рекомендаций с учётом риска

## Контекст

Аудит контура на сетке 2026 года (872 момента, шаг 6 ч, код `552a3b6`) показал: рекомендаций 30 (3,4%),
все «подача +2%»; у 29 из них P(S > 10) > 10%, у 3 — выше порога тревоги 20%. 532 отказа (61%) вызваны
только «несвежим» цетановым числом при значениях 51,7–53,8; 140 — тревогой прогноза без поиска
корректирующего действия; 50 — «расхождением» ПАК и Q21, которое исчезает после калибровки по ЛИМС.

## Решение

1. Запас по сере: P(S > 10) ≤ порога тревоги модели (0,2 на 3 ч) по квантилям out-of-fold остатков;
   без калиброванной ошибки — 1 мг/кг. Экономичный ход допустим только при P ≤ половины порога.
2. Тревога прогноза делает недопустимым удержание, а не весь контур; ищется самое дешёвое исправление.
3. Цетан: последняя проба с нижней границей по дрейфу (σ ≈ 0,31/√сут по пробам до момента решения),
   до 60 сут; недостающее закрывается присадкой ≤ 3%.
4. Предел шага по q99 часовых изменений 2023–2025; асимметричный отклик (вред — по большему коэффициенту).
5. Анализаторы сравниваются после калибровки по ЛИМС.

## Почему пересмотрено «не переносить 60 сут свежести CN в runtime»

Прежний запрет касался сравнения моделей: рост покрытия v4 шёл от ослабленной свежести, а не от модели.
Здесь свежесть не ослабляется вслепую: возраст пробы превращается в консервативную поправку, а её цена —
доза присадки, которая попадает в стоимость рекомендации. Правило 48 ч при месячном плане ЛИМС делало
ограничение ЦЧ непроверяемым по построению.
