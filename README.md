# OilCodeHack

Первая версия карты данных находится в [DataMap/Карта данных.md](DataMap/Карта%20данных.md), ветка `Human-DataMap`.

Открыть папку `DataMap` как vault в Obsidian. Перед первым открытием, из корня репозитория:

```powershell
python tools/setup_vault.py
```

Folder Notes 1.8.26 установится из репозитория и добавится к включённым плагинам. При необходимости разрешить community plugins в Obsidian. Личные настройки, темы, вкладки и прочие плагины остаются локальными: вся `.obsidian/` исключена из Git. Повторный запуск сохраняет настройки и существующую версию плагина.

Все 97 сигналов, 54 лабораторных ряда, 2 ПАК и 17 формул ВАК описаны со ссылками на источники, статистикой и ограничениями. Markdown читается также на GitHub; дополнительные плагины не обязательны. Большие исходные данные в репозиторий не включены, их SHA-256 есть в карте.

[Как поддерживать и проверять карту](tools/datamap/README.md).
