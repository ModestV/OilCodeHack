# Справочник данных

Реестр `backend/resources/registry.json` объединяет исходные метаданные без подмены наблюдений: 97 тегов КИП (71 АВТ и 26 гидроочистки), 54 пары ЛИМС и 2 пары ПАК. Идентификаторы сохраняют коды источника: `avt.T1`, `ht.F26`, `lims.avt.2.1.D15`, `lims.ht.2.Mg.Sulfur`, `pak.ht.Mg.Sulfur`.

## Исходная структура

- `Теги_хакатон.xlsx`, лист `КИП`: попарные колонки «описание / тег» для АВТ и 24-2000.
- ЛИМС: строка 1 — группа установки и точки, строка 2 — код показателя, строка 3 — единица, строка 4 — заявленное число значений; с строки 5 идут независимые пары дата/значение.
- ПАК: независимые пары A:B и D:E; имена в строке 1, единицы в строке 2, данные с строки 3.

## Единицы и оговорки

КИП не задаёт единицы. `°C` помечена как `inferred` только там, где описание прямо содержит «температура» и не зарегистрировано противоречие описания и масштаба; для остальных тегов единица `null`, статус `unknown`. Код тега сам по себе не служит основанием для вывода единицы.

В ЛИМС часть исходных заголовков единиц неверна. По указанию эксперта единицы определяются по названию показателя: температурные показатели — `°C`, `D15` — `кг/м³`, доли отгона — `% об.`. Исправленные единицы имеют статус `confirmed`.

Справочник ПАК называет серу `24-2000:Mg.Sulfur.Q`, а заголовок фактической выгрузки — `24-2000:Mg.Sulfur`; оба обозначения соответствуют `pak.ht.Mg.Sulfur`, установке гидроочистки и точке отбора 2. Исходный массовый `ppm` эквивалентен мг/кг; статус единицы `confirmed`. Обозначения °С/°C и кг/м3/кг/м³ нормализуются в °C и кг/м³.

Шесть главных лабораторных показателей точки гидроочистки 2: `Mg.Sulfur`, `D15`, `FlashPoint`, `CFPP`, `CloudPoint`, `95%.T`. Они помечены `primary:true`. Остальные показатели паспорта также включены в реестр.

## Проверка соответствия тегов

Короткие имена колонок CSV напрямую соответствуют тегам листа `КИП`; дополнительное масштабирование не применяется. Буквенный префикс не переопределяет подтверждённое описание. Управляющие переменные гидроочистки: `P8` — температура ГСС на входе Р-202, `T11` — массовый расход сырья, `F19` — давление на входе Р-202.

## Формулы ВАК

Экспертные версии применены для `24-2000:GODT:T90`, `T50`, `CloudPoint`, `CFPP`, `T95` и `AVT6:240-350:CFPP`. Они остаются `experimental`, пока не пройдут проверку на отложенной истории. Зависимость `Pipeline.95%.T` в T95 сопоставлена с `lims.ht.2.95%.T`; при расчёте используется только анализ, уже доступный с учётом четырёхчасовой задержки публикации. Алиас `Pipeline.D15` остаётся неразрешённым.

Порог серы 10 и сравнение ЛИМС/ПАК служат только мониторингом. Реестр не является полным заключением о соответствии конечного топлива спецификации.
