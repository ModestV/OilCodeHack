# Диагностика T95 и цетана

В рекомендациях и песочнице блок показывает исходные наблюдения гидроочистки,
точка 2, на момент расчёта решения. Это не прогноз конечного бленда и не
подтверждение введённых вручную свойств резервуаров.

`GET /api/datasets/{id}/quality-diagnostics?at=2026-08-07T00:00:00`
возвращает `diagnostic_only=true`, `can_authorize=false`, время расчёта,
наблюдения, оценки, использованные пробы и ограничения. Ошибка диагностики
показывается отдельно и не прерывает получение решения. При смене набора или
момента старый ответ не отображается, запрос отменяется.

## Время и качество данных

- Timestamp ЛИМС — отбор пробы; доступность принята как отбор + 4 часа.
- Возраст отсчитывается от отбора. Будущие и неопубликованные пробы исключены.
- Последняя проба показывается даже при недостоверности; автоматического
  отката к старой хорошей пробе нет. `invalid/conflict/suspect/flatline/gap`
  запрещают использование значения в оценке.
- Точные дубли одного timestamp считаются одной пробой; разные значения в
  один timestamp помечаются конфликтом. Null/NaN не заменяется соседней строкой.
- Возраст измерения сопоставляется с настройкой свежести ЛИМС. Отдельная
  область расчётных оценок ограничена 48 часами и не расширяется настройкой.
- Проверяются единицы нормализованного набора: T95/T50 — °C,
  D15 — кг/м³, цетановое число — ед.цет.ч. Неизвестные единицы блокируют оценку.
- Измеренный выход за ориентиры T95=360 / CN=51 показан отдельно, даже если
  оценка выглядит благоприятной. Эти ориентиры не являются спецификацией
  любого режима или доказательством качества конечного продукта.

## Оценки

**T95:** медиана последних трёх различных опубликованных проб (при наличии
одной или двух используется доступное число). Последняя должна быть не старше
48 ч; предыдущие могут быть старше, их времена и возраст раскрываются в UI.
Все включённые значения должны быть достоверными. Это более строгий runtime
фильтр, чем исследовательское исключение только invalid/conflict; метрики
исследования не приписываются автоматически изменённой выборке.

**Цетановый индекс:** `454.74 − 1641.416D + 774.74D² − 0.554T50 +
97.803(log10(T50))²`, где D = D15 / 1000. Берутся последние опубликованные
лабораторные D15/T50 не старше 48 ч. При разных timestamps явно указано
приближённое сочетание проб. ПАК не используется как незаметная замена ЛИМС.
Диапазоны 700–1000 кг/м³ и 100–450 °C — защита вычисления, не промышленные
пределы и не полная область применимости ASTM.

Источник формулы и сравнение с лабораторией —
[исследовательский отчёт](../reports/modeling/cetane-t95/README.md).
Индекс не равен измеренному цетановому числу и не подтверждает эффект присадки.
В историческом режиме оценки ретроспективны: метод был выбран после исследования
истории. Не заявляется его фактическая доступность в прошлые годы.

## Почему нет разрешения на выпуск

На общей выборке 2026 медиана T95 пропустила все 8 превышений, а расчётный
индекс с доступными на момент прогноза входами пропустил единственный факт
CN<51. Исследовательская граница T95 +8 °C не перенесена в runtime: она не
гарантирует безопасность отдельного случая и проверялась на ограниченной
выборке. Калиброванной границы для цетана нет.

Модуль `backend/quality_diagnostics.py` вызывается только отдельным GET endpoint;
`QualityAgent`, `ReliabilityAgent`, сценарный расчёт и safety gate не используют
его оценки. Свежесть 48 ч в контуре решения не ослаблена. LLM-слой ещё предстоит
подключить отдельно, с теми же ограничениями математического контура.

Проверка отсутствия воздействия на решение (каталог набора заменить своим):

```python
from pathlib import Path
from backend.agents import make_decision
from backend.scenarios import ScenarioRequest
from backend.quality_diagnostics import quality_diagnostics
p = Path("storage/hackathon")
request = ScenarioRequest(at="2026-08-07T00:00:00")
before = make_decision(p, request)
diagnostics = quality_diagnostics(p, request.at)
assert diagnostics["can_authorize"] is False
assert make_decision(p, request) == before
assert before["status"] == "abstain"
```
